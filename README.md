# 🚀 Space Shooter Game

A classic arcade space shooter game built with HTML5 Canvas, CSS, and JavaScript.

## 🎮 How to Play

- **Move Left/Right**: Arrow Keys (← →) or move your mouse/touch
- **Shoot**: Spacebar or click/tap on the game screen
- **Objective**: Destroy all alien enemies before they reach your ship
- **Lives**: You have 3 lives. Don't collide with enemies!

## ✨ Features

- Smooth animations and controls
- High score saved in browser localStorage
- Responsive design (works on desktop and mobile)
- Visual effects (shadows, glowing bullets)
- Progressive difficulty

## 🛠️ Technologies Used

- HTML5 Canvas
- CSS3 (Gradients, Shadows, Animations)
- Vanilla JavaScript (No frameworks)
